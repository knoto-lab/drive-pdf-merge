Drive PDF結合 プライバシーポリシー

制定日: 2026-10-08
提供者: 能登 和希

Chrome拡張機能「Drive PDF結合」（以下「本拡張機能」）における利用者情報の取り扱いを定めます。

1. 取得する情報と利用目的

本拡張機能は、利用者の許可を得て Google ドライブ API にアクセスし、次の情報を扱います。

  • 利用者がサイドパネルへドラッグしたファイル・フォルダの情報（ファイル名・種類・保存フォルダ）
    利用目的: 結合対象の一覧表示、PDF以外のファイルの除外、保存先フォルダの表示
  • 上記PDFファイルの内容
    利用目的: PDFの結合
  • 利用者が指定したファイル名
    利用目的: 結合したPDFを利用者のドライブに保存するため

本拡張機能がドライブ上で行う操作は、利用者がドラッグしたファイル・フォルダの読み取りと、結合したPDFの新規作成のみです。それ以外のファイルの閲覧・変更・削除は行いません。

2. 情報の保存・送信

  • PDFの読み込みと結合は、すべて利用者のブラウザ内（メモリ上）で行います
  • ファイルの内容・ファイル名などの情報を、提供者のサーバーその他の第三者へ送信・保存することはありません。通信先は Google ドライブ API のみです
  • 処理が終わった情報は保持せず、サイドパネルを閉じると破棄されます
  • Google の認証情報（アクセストークン）は Chrome が管理し、本拡張機能では保存しません

3. 第三者への提供

取得した情報を第三者に提供・販売することはありません。また、広告やその他の目的に利用することはありません。

4. Google API サービスのユーザーデータポリシーの遵守

本拡張機能による Google API から受け取った情報の使用および他のアプリへの転送は、限定的使用の要件を含む Google API Services User Data Policy に準拠します。

5. アクセス権の取り消し

利用者は、Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも本拡張機能のアクセス権を取り消せます。

6. 改定

本ポリシーを改定する場合は、このページで告知します。
